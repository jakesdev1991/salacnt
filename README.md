# salacnt

Simple counter web application with localStorage persistence. Clean, minimal HTML/CSS/JS implementation.

## Overview

A lightweight counter tool featuring:

- **Increment/Decrement**: Basic counter operations
- **Persistence**: localStorage for cross-session retention
- **Keyboard Shortcuts**: Arrow keys for quick control
- **Responsive Design**: Works on mobile and desktop
- **Zero Dependencies**: Pure HTML/CSS/JS

## Quick Start

```bash
# Serve locally
npx serve .
# or
python -m http.server 8000
```

Then open `http://localhost:8000`

## Files

- `index.html` - Main application
- `code.js` - Counter logic
